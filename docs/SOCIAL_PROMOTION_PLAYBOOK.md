# Social Promotion Playbook

Use this file as the default workflow for promoting Solmere Journal on social platforms.

## Goal

Drive qualified readers to:
- category pages
- topic clusters
- specific editorials
- supporting notes

Priority is trust and consistency, not viral volume.

## Core Positioning

Every post should feel like:
- controlled
- intimate
- decisive
- woman-led
- practical

Avoid:
- hype language
- "top 10" framing
- urgency spam
- generic affiliate tone

## Primary Channels

1. Pinterest
2. Instagram
3. TikTok
4. X (Twitter)
5. Reddit (selective)

## Link Strategy

Always link to one clear destination per post:
- `/topics/<slug>` for broad discovery
- `/notes/<slug>` for educational intent
- `/<category>/<slug>/` for direct product-intent traffic

Do not send social traffic directly to `/go/...` redirect links.

## Posting Cadence (Weekly)

- Pinterest: 5-7 pins/week
- Instagram: 3 feed posts/week + 3-5 stories/week
- TikTok: 3 short videos/week
- X: 5 posts/week
- Reddit: 1-2 high-quality contributions/week

## Content Mix

Use this ratio each week:
- 40% educational notes (problem-intent)
- 30% comparison/how-to/use-case content
- 30% editorial product pages

## Platform Execution

### Pinterest

Post format:
- title with query intent
- 2:3 vertical image
- short hook + 1 benefit + CTA

Template:
- Title: `How to Stop Wool Itch Without Giving Up Warmth`
- Description: `If you get sweaty indoors then freeze outside, your layers are the issue. Read the exact fix and outfit stack.`
- CTA: `Read the note`

Best links:
- notes
- how-to pages
- comparisons

### Instagram

Post format:
- 1 carousel or static image
- first slide: problem statement
- last slide: clear action

Caption template:
- Hook: `You probably don't need a new coat. You need a better layer stack.`
- Value: 2-4 short bullets
- CTA: `Read the full guide at the link in bio.`

Story format:
- frame 1: problem
- frame 2: fix
- frame 3: link sticker

### TikTok

Video structure (15-35s):
1. problem in first 2 seconds
2. 3-point fix
3. one-line CTA

Script template:
- `If you're sweaty indoors then freezing outside, do this.`
- `Base layer first. Thin mid-layer. Ventilated outer.`
- `I wrote the exact formulas on Solmere Journal.`

### X (Twitter)

Post type:
- short thread (3-5 posts)
- 1 idea per thread

Template:
1. `Most people are overdressed wrong in 40-55F.`
2. `Heavy sweater + heavy coat = sweat indoors, freeze outside.`
3. `Use breathable base + thin knit + weather shell.`
4. `Full breakdown: <link>`

### Reddit (Selective)

Only post where context fits:
- answer real user questions
- no promo-first posting
- include link only when truly helpful

Good approach:
- write useful answer first
- optionally add: `I wrote a longer breakdown here if useful: <link>`

## Hashtag/Keyword System

Use small, relevant sets (3-6 max):
- `#capsulewardrobe`
- `#jewelrycare`
- `#mensstyle`
- `#womensstyle`
- `#layering`
- `#transitionalstyle`

Also include plain-language phrases in captions:
- `thick thighs`
- `chafe`
- `sweaty indoors then freezing outside`
- `sensitive skin jewelry`

## Content Production Workflow

1. Pick one source page to promote.
2. Extract one problem statement.
3. Write one social-native hook.
4. Create one platform-specific version (Pin/IG/TikTok/X).
5. Publish with one destination URL.
6. Log result in tracker.

## CTA Bank

Rotate CTAs:
- `Read the full note`
- `Use this checklist`
- `See the comparison`
- `Open the how-to`
- `Read the full editorial`

## Quality Rules Before Posting

Check each post:
- one clear problem
- one clear recommendation
- one clear link
- no over-claims
- tone matches Solmere Journal voice

## What Not To Do

- Don’t post 10 product links at once.
- Don’t use fake urgency.
- Don’t copy/paste identical captions on every platform.
- Don’t force links into irrelevant communities.

## Monthly Review

At month end, identify:
- top 5 posts by click-through
- top 5 posts by saves/shares
- best-performing destination type (notes vs editorials vs comparisons)

Then double down on those formats next month.
