# Site Architecture

Use a clean static structure with meaningful URL paths.

```text
yourdomain.com/

    index.html  (Home)
    /categories/
        mens-underwear/
        womens-fashion/
        jewelry/
        maternity/
    /editorials/
        best-underwear-large-thighs/
        winter-coats-2026/
    /images/
        mens-underwear-01.jpg
```

## Non-Negotiable Rules

Do not:

- Use random hashed file names.
- Use query-string image URLs.
- Use CDN-only paths without page context.

Keep architecture sovereign and human-readable.
