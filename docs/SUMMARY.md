# Project Summary

This project is a premium editorial recommendation website that monetizes with affiliate links while feeling curated, decisive, and low-noise.

## Current Brand State

- Active brand language and visual system: `Stonebay Journal`.
- Tone: cold clarity, coastal-mineral, decisive and low-noise.
- Positioning: unisex editorial site with feminine-forward voice (not women-only wording).
- Domain cutover target: `stonebay.co` (not switched yet).

## Core Concept

- Not a store; an editorial authority model.
- Strong voice and constrained recommendations.
- Goal is reducing decision fatigue, not listing many options.

## Stack and Launch

- Static-first on GitHub Pages.
- No backend required at launch.
- Custom domain can be added later.

## Site Structure

- Clean folder-based URLs for home, categories, and editorials.
- Human-readable paths.
- Avoid hashed names, query-string image URLs, and contextless CDN paths.

## Editorial Model

- Each page is an editorial decision page.
- Primary recommendation with limited supporting picks.
- Authority comes from constraint.

## Personas (Penpal Strategy)

- Minimalist
- Performance Analyst
- Luxury Curator
- Practicalist

Each has distinct tone and category ownership, while sharing common formatting.

## UI and Layout

- Hero heading, decisive intro, featured product block, buy button, support rationale, secondary pick, disclosure.
- Premium style: large typography, whitespace, no clutter, no popups, no ad-noise.

## Affiliate Compliance

- Use official Amazon image sources/API only.
- Wrap product imagery in affiliate link properly.
- Include disclosure.
- Do not rehost Amazon images or deceptively cloak links.

## Automation Direction

- Input: ASIN, title, summary, category, persona.
- Output: structured page, affiliate link, image embed, canonical and meta tags.

## SEO and Image Strategy

- Use canonical tags and clean paths.
- Keep direct 200 responses and avoid redirect chains.
- Use sitemap + Search Console (and optional Yandex submission).

## Category and Home Model

- Top nav: Men, Women, Jewelry, Maternity, Baby.
- Category pages: 3-5 featured editorials + universal picks.
- Home: hero, carousel, monthly picks, universal section.

## Growth Roadmap

1. Launch static GitHub Pages
2. Add custom domain
3. Add structured data
4. Add original photography
5. Automate ASIN ingestion
6. Build backlinks and authority

## Execution Phases

- Phase 1: infrastructure and indexing basics.
- Phase 2: personas + flagship editorials + template consistency.
- Phase 3: affiliate automation.
- Phase 4: design polish.
- Phase 5: SEO/image control hardening.

## Master Principle

Make it feel like a private recommendation journal, not an affiliate marketing site.
