# Affiliate Integration (Compliance)

## Critical Rule

Do not self-host Amazon product images.

## Correct Structure

On each page:

- Use Amazon Product Advertising API images or official image embed tools.
- Wrap image in affiliate link.

Example:

```html
<a href="https://amazon.com/dp/ASIN?tag=kawaiishopai-20">
    <img src="official-amazon-image-url" alt="Product image">
</a>
```

## Must Include

- Affiliate disclosure.

## Do Not

- Download Amazon images.
- Rehost Amazon images.
- Deceptively cloak affiliate links.
