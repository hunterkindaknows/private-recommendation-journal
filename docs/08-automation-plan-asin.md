# Automation Plan (ASIN -> Auto Format)

With GitHub Pages (static), use one of:

- Option A: Jekyll-based generation
- Option B: Small JS build script

## Input Schema

Generator input fields:

- ASIN
- Title
- Short summary
- Category
- Persona

## Output Schema

Generator should produce:

- Affiliate link
- Image embed/API-linked image URL
- Structured page layout
- Canonical tag
- Meta tags

Purpose: scalability while preserving editorial consistency.
