# Editorial Model

Each "product page" is not a product page.

It is an editorial decision page.

## Example Positioning

Preferred title style:

- "Best Underwear for Men with Large Thighs"

Avoid:

- "Top 10 Options"
- "Compare 7 Brands"

## Recommendation Structure

Primary pattern:

- One clear winner.

Optional additions:

- Runner-up
- Budget pick
- Luxury pick

Keep recommendation count constrained.

Authority comes from constraint, not volume.
