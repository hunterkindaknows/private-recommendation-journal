# Page Structure and Premium UI

## Required Editorial Page Blocks

Each editorial page includes:

- Hero heading
- Short decisive intro
- One large featured product block
- Buy button
- Supporting explanation
- Secondary recommendation
- Affiliate disclosure

## Premium Layout Principles

- Large typography
- Generous whitespace
- No clutter
- No ad-like visual noise
- No popups
- No flashing discount banners

Goal: quiet authority.

## Imageless Launch Strategy

Launching without images is valid.

Use:

- Text-first editorial structure
- Clean typography
- Minimal iconography
- High-end visual hierarchy

Then stage in:

1. Authority first
2. Images second
3. Original photography third
