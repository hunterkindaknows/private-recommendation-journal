# Voice Strategy: Penpal Personas

This file intentionally isolates the persona model from UI/layout.

## Persona Set

Create 3-4 consistent editorial personas:

- The Minimalist
- The Performance Analyst
- The Luxury Curator
- The Practicalist

## Operating Rules

- Each persona writes in a distinct tone.
- Each persona owns specific categories.
- Internal formatting remains consistent across all personas.

## Strategic Benefit

This creates:

- Emotional segmentation
- Style differentiation
- Reader identification
